## Overview

This document provides all WhatsApp and email message templates for Call Setters, organized by use case. All messages should be sent via Go High Level (GHL) unless otherwise specified.

---

## Excluded Tags

**Do not send messages to leads with these tags:**

### Keap Tags
- Veto List
- Removed from 60 Day Academy - Bad Debt
- Not-Interested-In-Paying-For-Education
- 60 Day Finding Investor Academy
- 60 Day Property Investor Academy
- 60 Day Deal Packager Academy
- 60 Day Flipping Property Academy
- All Mentoring Clients

### WhatsApp-Specific Tags
- Invalid WhatsApp Account
- No WhatsApp account
- Not available on WhatsApp
- Stopwhatsapp
- WhatsApp not validated

## 1. Webinar & Discovery Call Invites for Did Not Attend Leads

### Scheduling
Send **once a week** to Did Not Attend Leads.

**Stop sending** once the lead has rebooked a webinar.

### WhatsApp Templates

Send in sequence, once per week:

1. `webinar_zac_dc_invite_01`
2. `webinar_zac_dc_invite_02`
3. `webinar_zac_dc_invite_03`
4. `webinar_zac_dc_invite_04`
5. `webinar_zac_dc_invite_05`

### Email Templates

1. `email_webinar_zac_dc_invite_01`
2. `email_webinar_zac_dc_invite_02`
3. `email_webinar_zac_dc_invite_03`
4. `email_webinar_zac_dc_invite_04`
5. `email_webinar_zac_dc_invite_05`

## Quick Reference Guide

### Message Flow Summary

| Stage | Action | Templates |
|-------|--------|-----------|
| **Did Not Attend** | Weekly invites | `webinar_zac_dc_invite_01-05` (WA & Email) |
| **After Voicemail** | Follow-up | `Vm1/3/5_webinar_zac_discovery_invite` (WA)<br/>`Vm2/4_webinar_zac_discovery_invite_email` (Email) |
| **Spoke - No Booking** | Follow-up invites | `webinar_zac_dc_invite_01-05` (WA) |
| **Webinar Booked** | Confirmation | `Confirmation_*_webinar_registered_zac_101` |
| **Pre-Webinar** | Reminders | 24h & 1h reminder templates |
| **Missing Links** | Send unique links | `fp/dp_unique_link_sms/email` |
| **Post-Webinar** | 101 Book + DC link | `101_Lessons_Book_and_Zac_Discovery_Call_*` |
| **Webinar Attended** | DC invites (13 weeks) | `book_discovery_call_zac_1a-8` (WA & Email) |
| **Replay Request** | Send replay | `dp/fp_webinar_replay` |
| **Missing Info** | Request details | `Missing_Email/Phone_Number_*` |

### Key Platforms

- **Go High Level (GHL)** - Primary messaging platform
- **WhatsApp** - Check for excluded tags before sending
- **Email** - Alternative communication channel

### Important Reminders

- ✅ Always check for excluded tags before sending messages
- ✅ Stop sending webinar invites once lead has rebooked
- ✅ Stop sending DC invites once discovery call is booked
- ✅ Include correct replay links before sending
- ✅ Follow the weekly/fortnightly schedule for DC invites
- ✅ Send reminders 24h and 1h before webinars
