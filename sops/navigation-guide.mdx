# SOP Navigation Guide

This guide helps you quickly find the right SOP for your needs and understand how different procedures connect to each other.

## 🗺️ Navigation Structure

### **New Structure (October 2025)**

The SOPs are now organized into logical groups for better navigation:

#### **1. Overview**
- **[Main SOP Hub](./index)** - Central starting point with role-based navigation

#### **2. Team Operations**
- **[Team Onboarding](./onboarding)** - New team member setup and integration
- **[Security Procedures](./security)** - Data protection and security protocols

#### **3. Sales & Lead Management**
- **[SPIN Qualification Scripts](./spinabt)** - Lead qualification methodology
- **[Call Handling Procedures](./call-handling)** - Discovery call management
- **[Calendly Procedures](./calendly-procedures)** - Appointment scheduling

#### **4. Client Services**
- **[Payment Handling](./payment-handling)** - Payment processing and client onboarding

## 🔄 Process Flow Navigation

### **Lead to Sale Process**
```
Lead Inquiry → SPIN Qualification → Appointment Booking → Discovery Call → Payment Processing
      ↓               ↓                    ↓                ↓                ↓
  [Marketing]    [SPIN Scripts]    [Calendly Proc.]   [Call Handling]   [Payment Proc.]
```

**Navigation Path:**
1. **Lead Qualification:** [SPIN Qualification Scripts](./spinabt)
2. **Appointment Booking:** [Calendly Procedures](./calendly-procedures)
3. **Discovery Calls:** [Call Handling Procedures](./call-handling)
4. **Payment Processing:** [Payment Handling](./payment-handling)

### **Team Management Process**
```
New Hire → Onboarding → Security Training → Role-Specific Training → Ongoing Support
    ↓          ↓             ↓                    ↓                    ↓
[Hiring]  [Onboarding]   [Security]        [Role SOPs]         [All SOPs]
```

**Navigation Path:**
1. **New Hire Setup:** [Team Onboarding](./onboarding)
2. **Security Training:** [Security Procedures](./security)
3. **Role Training:** Relevant SOPs based on position
4. **Ongoing Reference:** [Main SOP Hub](./index)

## 💡 Tips for Effective SOP Usage

### **For New Team Members:**
1. Start with [Team Onboarding](./onboarding)
2. Complete [Security Procedures](./security) training
3. Focus on role-specific SOPs
4. Use cross-references to understand connections

### **For Experienced Team Members:**
1. Use the [Main SOP Hub](./index) for quick access
2. Bookmark frequently used SOPs
3. Check "Related SOPs" sections for process improvements
4. Provide feedback for continuous improvement

### **For Training Others:**
1. Use the role-based navigation sections
2. Follow the process flow pathways
3. Emphasize cross-references and connections
4. Regular review and updates
